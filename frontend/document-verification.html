How Document Verification Works

1. Upload Document
Select the document you want to verify.
2. SHA-256 Hash Calculated
A unique cryptographic fingerprint (SHA-256) is calculated from the file content.
3. Compare with Blockchain
The hash is compared against proofs registered on the Arbitrum blockchain.
4. Result
MATCH ✓ = document is authentic. MISMATCH ✕ = document may have been modified.
